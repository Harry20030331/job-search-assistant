# Productivity UI revision

Maintenance date: 2026-10-31. User requested resuming an existing search directly in Status and a minimal professional interface based on the attached reference. Changes are on the current main checkout, uncommitted for review. Remote main was fetched and had no commit divergence before edits.

The shared design system uses local Inter, white/black/light gray, restrained status colors and compact spacing. Welcome retains the three explicit candidate choices. New candidate retains LinkedIn, pasted text and PDF, source review and fact confirmation. Saved searches keep full workspace paths under Location to disambiguate similarly named candidates. Existing-search resume now opens Status; new setup and initial example entry still open Profile.

Status uses a semantic table, an All tab and lifecycle tabs. Selection, row numbering, stable IDs, direction labels, safe refresh and task-derived states remain in force. The Apply button is available in All or Shortlisted when eligible jobs are selected. Review preserves its independent content approval and Submit controls; Interview preserves exact-version Plan approval, practice generation and debrief provenance. No employer, Google or model action is triggered by the visual change.

Inter is bundled from the official rsms/inter repository (`docs/font-files/InterVariable.woff2`), with its SIL Open Font License in `src/workbench/assets/Inter-LICENSE.txt`. Both local services serve the same fixed asset route. No external font request or new runtime dependency is needed. The distribution check verifies this exact binary by digest rather than decoding it as English text.

Browser checks use the existing isolated Alex Liu workspace and a separate authored fictional Review checkpoint. They cover existing-search landing, All/Shortlisted, selection/Apply count, source tabs, Review answer requirements and Interview rendering. No applications were submitted, no models called and no live job discovery was performed. Responsive CSS retains local table/tab scrolling and scrollable navigation.
