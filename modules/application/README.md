# Application Support

**Owner:** Yuming Feng

Build the application pipeline and its evaluation.

- **Input:** A user-selected job and authorized access to the user's external profile and resume.
- **Workflow:** Fill, validate, ask about unknowns, resume after clarification, and submit when authorized.
- **Output:** Reviewable application content, unresolved questions, and an application status record.
- **User role:** Supply missing facts and review/authorize submission.
- **Evaluation:** Resettable forms across layouts and complete/incomplete profiles; measure correctness, completeness, uncertainty handling, and corrective user effort.

Keep module-specific skills, tools, and evaluation code here. Adapt reusable logic from prior work only after removing personal data; never copy private history.
