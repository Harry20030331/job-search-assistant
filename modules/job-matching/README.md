# Job Matching

**Owner:** Hannah Guan

Build the job-matching pipeline and its evaluation.

- **Input:** User profile, resume, preferences, and job information.
- **Workflow:** Retrieve jobs, analyze fit and gaps, present recommendations, and refine with feedback.
- **Output:** Job candidates with source links, evidence, uncertainties, and user selection status.
- **User role:** Provide preferences and decide which opportunities to pursue.
- **Evaluation:** Historical jobs with varied profiles; assess relevance and analysis quality against basic task instructions.

Keep module-specific skills, tools, and evaluation code here. Define the handoff to Application Support jointly with its owner.
